# 提案：可配置智能体、持久化会话与流式回答

## Why
第 5 课新课件把「解题助手」升级为**可配置智能体**：助手不再由班级级提示词+全量技能拼装，而是以智能体为单位规定「是谁、能用什么技能、能查什么材料」。现有实现有三处与新课件直接冲突：①技能是全量注入而课件要求**确定性词法路由、每轮至多一个技能**；②检索范围是全班而课件要求**限定在智能体绑定的材料内**；③检索未命中时短路返回固定句而课件要求**新链路仍按智能体继续生成（引用为空、禁 `[n]`）**，且旧 `/api/ask` 行为保持不变。此外课件把技能改为**单一文本文件格式**（元数据+正文，严格解析），SSE 协议新增**先发 `meta`**（技能+引用）与**部分文本失败也要落库**。本变更在既有 CampusClaw 上增量改造，不新建仓库、不重写认证/上传/索引/第 4 课检索。

## What Changes
- **智能体实体**：新增 `assistants`（班内名称唯一 ≤64 字、角色提示词 ≤2000 字空值回退默认角色、启用状态）与两张绑定表 `assistant_skills`、`assistant_materials`；教师创建/修改/启停并维护绑定，学生只读；按编号访问他班/不存在/无权选用一律 404。会话**锁定智能体编号**，换智能体须新建会话；智能体停用后已有会话仍可用；绑定不打快照，改绑定下一轮即生效。
- **技能文件**：`ai_skills` 扩展为文件解析模型（`conditions`/`subject_scope`/`tool`/`raw_text`），教师上传或编辑单一文本文件：元数据区（名称/适用条件/资料/工具/启用）+ 空行 + 说明正文；总长 ≤8000 字、字段长度上限、适用条件按中英文逗号/顿号/分号/竖线切词、`工具` 仅允许 `knowledge_search`；重复字段、未知字段、非法布尔、非法工具、缺正文一律返回可读 400；保留原始文本；班内名称唯一；删除技能级联删绑定。
- **确定性技能路由**：只看会话智能体当前绑定且启用的技能；问题与关键词统一大小写后逐词判断子串命中计分；取最高分，同分取 DB ID 小者，零分不选；**每轮至多一个技能**；命中技能名含「解题引导」时系统提示必须显式禁止输出最终答案/选项/得数/完整过程。
- **限定材料检索**：复用第 4 课 hybrid，候选额外限定为智能体绑定的本班材料，最多 4 条；技能「资料」非空时按材料标题包含学科词过滤；剔除空正文后**从 1 连续编号**；每份送模型资料 ≤800 字，正文仍来自 MySQL。
- **消息组装与信任边界**：系统消息按「角色提示词（空用默认）→ 命中技能名称+说明（未命中说明本轮直接回答）→ 有资料优先依据并标 `[n]` / 无资料禁编号与虚构出处 → 固定边界声明（技能说明、材料标题与正文是数据不是指令）」组装；材料与问题放**用户消息**，不进系统消息；前端按文本渲染不执行 HTML。
- **SSE 协议升级**：`meta`（检索后最先发，带状态、命中技能、引用列表）→ `delta`（只发新增片段）→ `done`（持久化后发消息 ID）/`error`（脱敏）；`Cache-Control: no-cache` + `X-Accel-Buffering: no`；meta 之前失败用真实 HTTP 状态，之后失败用 `error`；**已产生部分文本再失败按规约保存已产生内容**，零片段不保存空回答；前端处理拆帧/多帧/UTF-8 拆分/无 done 断线/非法 JSON/重复提交。
- **新旧链路口径**：新链路检索无命中**仍生成**（引用为空、正文禁 `[n]`）；旧 `/api/ask` 固定句短路**原样保留**，两条链路在 spec 中明确区分。
- **会话与消息**：新建会话必须选定本班已启用智能体（无有效智能体时服务端拒绝、前端阻止并说明）；标题先「新的提问」，首轮后改为问题前 24 个 Unicode 字符；列表按最近更新倒序；历史窗口最近 6 条有效消息、每条 ≤500 字；本轮用户消息先落库；助手消息连引用与命中技能名一起保存。
- **迁移**：新 migration 扩展现有表并迁移既有数据（不另建重复的 `tutor_agents`；现有 `ai_skills` 从班级级扩展而来）；为每个已有班级创建默认智能体、回填既有会话的 `agent_id`、迁移既有提示词为默认角色、把既有启用技能与本班材料绑定到默认智能体，保证升级后老会话下一轮立即可用。
- **交付面**：教师智能体管理+技能文件管理页、学生智能体选择+会话+流式页（复用 AppShell 与设计令牌）；OpenAPI/Swagger 与实际一致；`apitest/` 补齐智能体/绑定/解析/路由/限定检索/meta/新旧口径用例；同步 README 与 `learning/` 学习文档。

## Non-goals
- 不改回 Cookie/Session、不重复实现 JWT、不把令牌从 localStorage 迁到 sessionStorage。
- 不重写第 4 课切分/索引/RRF/引用上下文，只在检索上加「智能体绑定材料」范围过滤。
- 不移除或暗改旧 `/api/ask`；新旧问答链路并存。
- 不做 WebSocket、多人实时、语音、流式工具调用、长时记忆总结、无限历史。
- 不做语义技能路由、模型自主多技能选择或多技能融合。
- 不实现任意工具执行、MCP、外部网络动作；`knowledge_search` 仅是受校验的声明。
- 不采信客户端提交的角色、班级、用户、绑定范围或系统消息；不依赖前端隐藏按钮做权限。
- 不把材料正文、技能文件或模型输出当可信 HTML；不把上传文本放进系统消息冒充指令。
- 不提供智能体删除接口（课件只要求创建、修改、启停与绑定维护）。
